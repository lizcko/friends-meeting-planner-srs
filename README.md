# Планировщик встреч с друзьями

Лабораторная работа №1 по разработке и управлению требованиями к программному обеспечению.

## О проекте

«Планировщик встреч с друзьями» — приложение для организации совместных встреч, согласования даты и времени и проведения голосования между участниками.

## Основные возможности

- создание новой встречи;
- добавление участников;
- предложение нескольких вариантов даты и времени;
- голосование участников;
- просмотр результатов голосования;
- выбор итоговой даты и времени встречи.

## Документация

Техническое задание размещено в Wiki репозитория.

Функциональные требования подробно описаны в Issues.

Для каждой Issue указаны:

- User Story;
- критерии приёмки;
- связь с техническим заданием.
