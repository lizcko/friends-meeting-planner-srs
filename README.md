
# Планировщик встреч с друзьями

## О проекте

«Планировщик встреч с друзьями» — учебное веб-приложение для организации совместных встреч, управления списком участников и выбора удобной даты и времени путём голосования.

Проект разработан в рамках лабораторных работ по разработке программного обеспечения, управлению требованиями, планированию и контролю версий.

## Цель проекта

Создать удобный инструмент, позволяющий организатору предложить встречу, добавить участников, определить возможные даты и выбрать наиболее подходящий вариант на основе результатов голосования.

## Реализованные возможности

- Создание встречи с названием, описанием и местом проведения.
- Отображение списка созданных встреч.
- Добавление участников к встрече.
- Удаление участников.
- Проверка повторного добавления участника.
- Добавление нескольких вариантов даты и времени.
- Проверка повторяющихся вариантов.
- Выбор участника для голосования.
- Голосование за один или несколько вариантов.
- Изменение ранее сохранённого голоса.
- Автоматический подсчёт голосов.
- Выделение вариантов с наибольшим количеством голосов.
- Сохранение данных в localStorage.
- Адаптивный интерфейс.

## Запуск приложения

Приложение не требует установки дополнительных библиотек или сервера.

### Способ 1. GitHub Pages

Открыть опубликованное приложение:

https://lizcko.github.io/friends-meeting-planner-srs/

### Способ 2. Локальный запуск

1. Скачать репозиторий с GitHub.
2. Распаковать архив на компьютер.
3. Открыть файл index.html в современном браузере.
4. Начать создание встреч.

Для корректной работы рекомендуется использовать актуальную версию Google Chrome, Microsoft Edge или Firefox.

## Инструкция пользователя

1. Заполнить название, описание и место встречи.
2. Нажать «Создать встречу».
3. Добавить участников.
4. Предложить несколько вариантов даты и времени.
5. Выбрать участника в разделе «Голосование».
6. Отметить подходящие варианты.
7. Нажать «Сохранить голос».
8. Просмотреть результаты голосования.

Данные сохраняются в браузере и доступны после обновления страницы.

## Контроль версий

Разработка выполнялась в отдельных ветках:

- feature/create-meeting — создание встреч.
- feature/manage-participants — управление участниками.
- feature/voting — голосование за даты и время.

Для объединения изменений использовались Pull Requests.

Основные Pull Requests:

- PR #26 — реализация создания встреч.
- PR #27 — управление участниками.
- PR #28 — голосование за даты и время.

## Автоматическая проверка качества

В проекте настроен GitHub Actions.

Файл конфигурации:

.github/workflows/ci.yml

При изменениях в основной ветке выполняются:

1. Проверка наличия основных файлов.
2. Проверка синтаксиса JavaScript.
3. Проверка наличия ключевых функций приложения.

Также предусмотрен запуск проверок при создании Pull Request в ветку main.

## Ограничения текущей версии

Приложение представляет собой учебный прототип.

- Данные сохраняются только в браузере пользователя.
- Серверная база данных отсутствует.
- Синхронизация между разными устройствами не реализована.
- Авторизация пользователей отсутствует.
- Выбор участника в списке не является подтверждением личности.
- Итоговая дата встречи автоматически не утверждается.
- Автоматические проверки не заменяют полноценное функциональное тестирование.
