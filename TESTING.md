
# Результаты тестирования

## Проект
Планировщик встреч с друзьями

## Проверенные функции

### 1. Интерфейс голосования — Issue #17
- Отображаются варианты даты и времени.
- Пользователь может выбрать участника.
- Доступен выбор нескольких вариантов.
- Реализована кнопка «Сохранить голос».
- После сохранения появляется подтверждение.

### 2. Голосование за несколько вариантов — Issue #19
- Участник может отметить несколько дат.
- Голоса сохраняются отдельно для каждой встречи.
- Повторное сохранение не удваивает голоса.
- После обновления страницы результаты сохраняются.

### 3. Подсчёт результатов — Issue #21
- Для каждого варианта подсчитываются голоса.
- Результаты отображаются в карточке встречи.
- Лидирующие варианты выделяются.
- При изменении голосов результаты пересчитываются.
- При равенстве голосов выделяются все лидеры.

## Среда тестирования

- Веб-браузер Google Chrome.
- GitHub Pages.
- Хранение данных в localStorage.

## Результат

Основные сценарии голосования проверены вручную.

Ограничение: приложение работает как локальный учебный прототип без синхронизации между устройствами.
